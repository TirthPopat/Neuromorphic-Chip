Antigravity Neurochip: Project Final PPA Report

Executive Summary

This report details the architectural evolution and Power, Performance, and Area (PPA) scaling of the Antigravity Neuromorphic Chip from its baseline SRAM implementation (Phase 6) to its maximum physically realized RRAM implementation (Phase 8).

By substituting massive SRAM memory arrays with high-density RRAM crossbar hard macros, we unlocked unprecedented silicon utilization, transitioning the design bottleneck from Silicon Area to CAD Tool RAM Capacity, ultimately achieving an 8-Core highly parallel learning architecture.

Phase 6: Baseline 4-Core SRAM Architecture

  • Description: 4 LIF Neurons per core with standard 6T SRAM for synaptic weight storage.
  • Memory Technology: Sky130 2KB SRAM Macros (x4)
  • Die Area: 2.05 mm2
  • Standard Cell Count: ~20,000 logic gates
  • Status: Baseline established.

Phase 7: RRAM Shrink (4-Core)

  • Description: Swapped the SRAM macros with Custom RRAM Crossbar behavioral hard macros. Memory became a 1-cycle combinational VMM matrix.
  • Memory Technology: 150um x 100um RRAM Crossbar Macros (x4)
  • Die Area: 0.38 mm2
  • Area Reduction: 81.5% smaller than the SRAM equivalent!
  • Standard Cell Count: ~20,000 logic gates
  • Status: Successfully routed and GDS generated.

Phase 8: Scaling to Massive Parallelism (8-Core)

  • Description: Used the freed-up silicon area to horizontally scale the architecture. Introduced a parameterized Verilog framework with a 9-bit Network-on-Chip (NoC), Round-Robin arbitration, and 8 parallel learning cores.
  • Memory Technology: RRAM Crossbar Macros (x8)
  • Standard Cell Count: 72,781 logic gates
  • Internal Wire Nets: 247,500
  • Peak RAM Usage (EDA Tool): ~8.4 GB during Detailed Routing
  • Status: Successfully routed and GDS generated.

(Note: An attempt was made to scale to 16 cores (1.1 million logic gates), but the OpenROAD global placement algorithms exceeded the 14GB RAM limitation of the Docker host environment.)

Conclusion

The architectural goal was a resounding success. The RRAM memory substitution provided such an extreme density advantage that we were able to completely duplicate the neurochip’s processing capability multiple times over without being bounded by the silicon die limitations of the baseline SRAM architecture.
